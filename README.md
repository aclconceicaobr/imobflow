# Imobbay

CRM imobiliário em SaaS para imobiliárias de até 20 corretores: imóveis, leads, funil, agenda, captação e WhatsApp.

- Como rodar e configurar: [docs/operacao.md](docs/operacao.md)
- Regras para quem escreve código (pessoas e IA): [CLAUDE.md](CLAUDE.md)
- Decisões aprovadas: [docs/decisoes.md](docs/decisoes.md)
- Regras de negócio: [docs/regras-de-negocio.md](docs/regras-de-negocio.md)
- Segurança e RLS: [docs/seguranca-rls.md](docs/seguranca-rls.md)

```bash
corepack enable
pnpm install
cp .env.example .env.local   # preencha os valores
pnpm dev
```
